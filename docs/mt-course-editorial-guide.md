# 大地电磁讲义中文写作与编辑规范

这份规范用于保证长期更新的课程博客具有自然、准确、连续的母语中文表达，而不是模板化的讲稿或软件说明书。

## 文风与读者

- **先说事实，再说解释。** 优先描述实际发生的变化、符号之间的关系和可以验证的现象。
- **数学浅显但不删步骤。** 每个新符号首次出现就解释，用具体数值示范后再推广一般公式，推导中尽量保留真正重要的中间代数步骤。
- **博客以完整逻辑单元分段。** 同一段内的句子应有明确关系，避免把一句话独立成段当成修辞节奏。
- **中文自然、稍具学术性。** 允许恰当类比与少量幽默，避免粗俗、卖弄、拟人化过度或每节固定放一个笑话。
- **保留科学限定。** 具体的近似条件、边界条件、统计假设和地球物理多解性是知识内容，不属于需要清除的“AI 味”。

## 避免的句式与改写方式

| 容易显得机械的句式 | 更合适的思路 |
|---|---|
| “这不是……而是……”重复出现 | 先直接写出实际机制或公式的适用条件；只有确实需要比较时才用对立结构 |
| “并不意味着……”“不能证明……”每段都出现 | 具体解释哪些证据能支持什么结论、还缺什么约束 |
| “请记住”“一定要注意”“千万别误以为” | 说明定义、单位和实际后果，让读者自己理解重要性 |
| “我们已经学会了……接下来我们要……”在每个小节反复出现 | 使用一个承上启下的物理问题或数学目标完成自然过渡 |
| “不只是……更是……”等空泛拔高 | 给出实际实验现象、可计算公式或一个可复现的结果 |
| “图很漂亮但不等于真实”等笼统警告 | 讨论测站位置、数据敏感频段、反演误差权重与恢复试验 |
| 连续使用三条平行论点和逐节机械总结 | 根据问题的发展安排段落，只有确实利于学习时才列清单 |

## 幽默的尺度

幽默优先来自学习中的真实麻烦，帮助记忆物理或统计概念。例如：

- “岩石里的低阻区不会附赠一张写着‘我是岩浆房’的身份证”，可以提醒**电性异常与地质成因的距离**。
- “反演模型过度平滑，相当于给地质界面加了磨皮滤镜”，可以解释**正则化的分辨率代价**。
- “坐标错转了九十度，图依然可能非常漂亮”，可以提醒**坐标和图像一致性校核**。

不为了风趣而干扰数学推导，也不强行每段加入笑话。

## 长篇课程结构

正式教程分为 17 篇。每篇开头保留篇内目录，使用 Markdown 二级、三级标题建立层次，保持 LaTeX 数学公式原样可用。

新内容应检查：

1. 是否重复了其他单元的完整前言或旧版短文导航；
2. 内部链接是否指向当前正式教程的相应锚点；
3. `e^{+i\omega t}`、NED 坐标、`B/H` 的区别是否依旧一致；
4. 例题数值与量纲能否独立核算；
5. 地质解释是否区分观测结果、反演参数、稳定结构和候选物性机制。
